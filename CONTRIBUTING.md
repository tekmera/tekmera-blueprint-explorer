# Contribute to 🤗 Tekmera Fusion Explorer

First off, thank you for considering contributing to Tekmera Fusion Explorer! It's people like you that make open source such a great community. 

This document provides guidelines and workflows for contributing to this project.

## Code of Conduct

By participating in this project, you are expected to uphold our [Code of Conduct](\.github\CODE_OF_CONDUCT.md). Please report unacceptable behavior to the project maintainers.

## Ways to Contribute?

### Reporting Bugs

Before creating bug reports, please check the existing issues to see if the problem has already been reported. When you are creating a bug report, please include as many details as possible:
* Use a clear and descriptive title.
* Describe the exact steps to reproduce the problem.
* Describe the behavior you observed after following the steps and point out what exactly is the bug.
* Explain which behavior you expected to see instead and why.
* Include screenshots and details about your environment (OS, versions) if applicable.

### Suggesting Enhancements

Enhancement suggestions are tracked as GitHub issues. When creating an enhancement request, please provide:
* A clear and descriptive title.
* A step-by-step description of the suggested enhancement.
* Specific examples to demonstrate the steps and the requested feature.
* A description of the current behavior and how your suggestion differs from it.
* An explanation of why this enhancement would be useful to most users.

## Pull Request Process

1. **Fork the repository** and create your branch from `main`.
2. **Branch naming:** Use a descriptive prefix for your branch (e.g., `feature/add-login`, `bugfix/issue-12`, `docs/update-readme`).
3. **Write tests:** If you've added code that should be tested, add tests.
4. **Ensure tests pass:** Make sure all existing and new tests pass locally before submitting.
5. **Update documentation:** Update the `README.md` or other documentation files with details of changes to the interface or usage.
6. **Submit:** Open a Pull Request using the provided template. Ensure your PR description clearly describes the problem and solution.

## Coding Standards

* **Commit Messages:** Write clear, concise commit messages using the imperative mood (e.g., "Fix database connection timeout" ).
* **Styleguides:** Black, isort, flake8, and mypy.
* **Testing:** pytest and pytest-cov.

Thank you for contributing!
